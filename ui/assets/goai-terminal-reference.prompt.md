# GOAI terminal reference image

This reference was generated after the user approved a Bloomberg-inspired
institutional terminal direction. It is a visual calibration asset only; it
does not copy Bloomberg branding or screen layout, and it is not rendered as a
static page background.

The reference image's original grammar was: near-black graphite shell, amber
command/selection state, restrained green and red status colors, numbered
workspace rail, top keyboard command strip, dense quote/chart/options-chain
center, and a right decision inspector. At the user's request, the shipped
implementation remaps command/selection typography to cool cyan while keeping
green/red semantic states. The implemented chart must disclose when the frozen
snapshot lacks time-series data instead of inventing candles.
