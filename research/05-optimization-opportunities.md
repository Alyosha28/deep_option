# 05 优化机会与功能优先级（Optimization Opportunities）

## 差异化功能（按评审价值排序）

1. **对话式场景 → 账户约束求解**：输入“腾讯业绩、方向不定、10 万港币、跨式” → 输出行权价/到期/手数/成本/保证金/盈亏平衡/IV crush 提示。核心卖点，别做成聊天框。
2. **流动性评分 + 主动预警**：PBA、报价量、OI 趋势、报价新鲜度；价差过宽预警并量化“价差成本吃掉预期收益 X%”。港股期权真实痛点。
3. **业绩事件模块**：隐含波动（ATM straddle/IV）vs 历史实现波动；IV Rank；crush 预警；仓位/离场计划。
4. **账户约束感知**：合约乘数（腾讯=100 股）、现金/保证金、风险规则（单笔 ≤5% 等）反推手数与缓冲。
5. **港美股差异显性化**：美式/欧式、周选/月选、实物/现金交割、价差结构——每条建议都带市场规则说明。
6. **审计与溯源（C）**：每个数字来自计算引擎 + 数据快照 + 时间戳；可校验审计日志；透明规则引擎。
7. **GEX 风格流量分析**（加分项）：按公开数据算近似 gamma exposure/关键价位；注意 moomoo Engine 同向竞争。

## 技术优化点

- 定价引擎自建：欧式 BS、美式二叉树/bump-and-reprice；不依赖数据源自带 Greeks。
- 流动性评分公式化：score = w1*PBA + w2*OI_z + w3*vol_z + w4*quote_size_z（学术对齐 PBA 口径），事件窗口（业绩前）调权。
- 快照录制：比赛期间每天落库 → 自有历史期权数据（长期护城河）；回放模式保证 Demo 稳定。
- Agent 架构：参考 TradingAgents——分析师/研究员/交易员/风控经理，风控一票否决；人机闭环（人类确认才可下单）。
- 数据层：FutuAdapter（实时）→ 统一 Quote 模型 → SnapshotRecorder → ReplayMode → FallbackAdapter(Yahoo/Alpaca)。
- 安全（C）：密钥不入库、行情/新闻文本防注入、审计日志完整性（哈希链）、公开仓库扫描。

## Demo 取舍（3 人团队）

- MVP 只做一条主链路：腾讯业绩跨式（0700.HK）。数据=富途实时或录制快照。
- 四面板终端：对话 / 期权链（流动性染色）/ 收益图+Greeks+账户检查 / 预警流。
- 不做：App、多标的、多场景、真实下单（模拟盘可展示但非必需）。
- 现场演示预案：OpenD 掉线→回放；评委问数据→展示来源与授权说明；问合规→展示审计与免责。

## 威胁与应对

- moomoo Engine（gamma/异动/策略实验室）→ 我们拼“对话场景+账户约束+流动性预警+审计”，不做面板军备竞赛。
- moontower.ai（观点→期权表达）→ 持续跟踪；我们在港美股双市场 + 零售 + 可复核审计上有差异。
- Option Alpha（自动化规则）→ 我们吸收其规则库思想，但面向散户与半专业、强调事件与流动性。

## 评审维度对照（Boundless）

行业场景价值（金融+期权）→ Hero 用例与数据证据；Agent 能力与任务闭环 → 五 Agent + 风控门；产品体验与 Demo 完成度 → 四面板 + 回放；技术实现与可复现 → 自研定价/流动性/审计；安全合规与开放复用 → C 的合规页 + 透明规则引擎。
