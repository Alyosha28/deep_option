# 01 市场格局与竞品（Market Landscape）

## 券商/平台现状

### 富途 / moomoo
- 港美股期权均可交易；港股及期权 LV1 实时报价自 2023-12 起免费开放（全港首家）。
- 美股期权实时 L1 约 2.99 USD/月、L2 约 3.99 USD/月（非专业用户）；美股期权毫秒级深度报价（~300ms）。
- Futubull AI（DeepSeek）：行情/研究问答 + 是/否问答引导生成策略——不是自由场景解析。
- Moomoo Engine（2026-07 官宣，进行中）：L2 期权数据、策略实验室、P&L 模拟器、gamma exposure 追踪、异常期权活动预警、期权筛选器、无代码算法交易 → 直接威胁“分析面板”类功能。
- 官方 AI Skill Hub：futuapi（见 02 数据源），自然语言调用 56 个 API，覆盖行情/交易/推送，默认模拟盘。

### 老虎证券
- 港股 + 美股期权；TigerOpen API 提供期权链、Greeks、多腿组合、盘口深度、实时推送。
- 界面友好、港股打新+期权组合体验；无自由场景 Agent。

### IBKR
- 专业级：TWS 策略创建器（多腿）、OptionTrader、Probability Lab、隐含波动率曲面、压力测试、保证金类 excess liquidity 预警。
- 学习曲线陡；无自然语言层；期权流动性工具偏做市商向（IBUSOPT）。

### Bloomberg
- 金标准：OMON（期权监控）、OVME（定价/结构）、OSA（情景分析）、Tradebook 流动性捕获。
- 机构级、美股为主、价格门槛极高；无对话 Agent；港股期权场景弱。

## 独立工具/竞品概念

- OptionStrat：策略构建器、收益图、优化器、期权流；静态工具，无账户约束、无实时监测预警。
- SpotGamma：GEX/gamma exposure、HIRO、关键价位；机构流向数据，美股为主。
- moontower.ai（Kris Abdelmessih）：给“有观点的交易者”提供波动率镜头，把观点表达成期权结构 → 与我们的产品概念最接近，需持续跟踪。
- Option Alpha：规则化自动交易（ITM 概率窗口、GTC 止盈、roll）；偏卖权自动化。
- VolRadar / ORATS / ApexVol：IV Rank、RV Ratio、IV crush 数据与研究——是我们事件模块的参考指标源。
- tastytrade / tastylive：研究驱动平台，16Δ/45DTE 等公开研究——方法论参考。

## 缺口（我们的机会）

1. 自由场景自然语言 → 账户约束求解的完整方案（富途 AI 只做是/否引导）。
2. 流动性主动监测与预警（价差/报价量/持仓量/新鲜度），港股期权尤其缺失。
3. 账户约束感知的仓位构建（现金/保证金/合约乘数/风险规则反推方案）。
4. 事件驱动闭环（业绩：隐含波动 vs 实现波动、IV crush、持仓计划）。
5. 港美股期权差异显性化（美式/欧式、周选/月选、实物/现金交割、价差结构）。
6. 审计溯源 + 透明规则（合规叙事，券商黑盒做不到）。
7. “Bloomberg 流程能力”的零售价格 + 中文优先。
