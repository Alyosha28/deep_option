# 账户约束与风险审计检查单

## 账户参数模板

```json
{
  "account": "sim_100k_hkd",
  "currency": "HKD",
  "cash": 100000,
  "margin_available": 0,
  "risk_budget_pct": 5
}
```

## 硬规则（任一不满足 → BLOCK，禁止进入下单步骤）

- 完整策略组合的最大亏损 ≤ 账户净值 × risk_budget_pct
- 现金账户：权利金支出 ≤ 可用现金
- 保证金账户：组合保证金占用 ≤ 可用保证金
- 期权张数 ≤ `get_max_trd_qtys` 返回的最大可交易量
- 持仓限额与 LOP 申报：必须按当前 HKEX 规则、产品类别和账户现有持仓动态解析；无法验证时 BLOCK

## 港美股差异

- 合约乘数：美股 = 100 股/合约；港股 = 一手正股（如 0700 为 100 股/张，须按 HKEX 合约规格页复核）
- 美式期权可提前行权（注意股息/assignment 风险）；欧式仅到期行权
- 交割方式：个股实物交割；指数期权现金交割

## 风险审计输出格式

PASS / BLOCK + 违规项列表 + 建议调整（张数 / 行权价 / 到期月），并写入审计日志。
