# 给做 PPT 的朋友：GOAI 用人话讲一遍

这个项目最值钱的地方，一句话就能说完：**它敢对用户说"别买"。**

别的金融产品都急着教你赚钱，它每次算完都先问一句：这笔交易，值不值。算下来不值，它就明说。这个"明说"不是产品缺陷，是整个项目的心脏。PPT 做得好不好，就看你能不能把这个心脏讲出来。

## 一、它是干嘛的

用户用大白话说一句话，比如：

> "腾讯马上发财报了，方向看不准。我账户里有 10 万港币，最多亏 5%，帮我看看买个跨式期权行不行。"

系统听完，自己把这句话拆成任务，查数据、算价格、核风险，最后还给用户一张"决策卡"。卡上写清楚：要花多少钱、最多亏多少、什么情况下赚钱、数据是哪天哪一刻的、结论是什么。

结论只有四种：不买（NO_TRADE）、拦下（BLOCK）、只能当草稿（DRAFT_ONLY）、可以请你确认下单（READY_FOR_CONFIRMATION）。

注意：**"不买"和"拦下"都是成功的产品结果**。这不是谦词，是卖点。评委里一定有人被一堆"帮你赚钱"的项目包围，突然看到一个敢说"别买"的，会抬头。

## 二、用户是谁，痛点在哪

用户是有基础期权知识、用富途炒港美股的人。他们会看 Call/Put，但没人帮他们做完整的功课。

他们的痛苦很具体：

- 看行情在一个页面，看合约规则在另一个页面，算盈亏得自己开表格，账户还剩多少钱心里也没底——**信息是散的**；
- 软件里看到的"价格"常常不是真正能成交的价格（没算买卖价差、手续费、滑点）——**数字是虚的**；
- 港股期权的规则和美股不一样（美式、实物交割、行权风险），照搬美股经验会踩坑——**规则是容易搞混的**；
- 最要命的一条：**大模型会编数字**。你问 ChatGPT"这个跨式值不值"，它能给你算出一个看起来头头是道、其实是编出来的数字。金融领域编数字，是要命的。

我们做的就是把散的信息收拢、把虚的数字做实、把容易搞混的规则显性化，并且从机制上保证：**没有一个数字是大模型拍脑袋想出来的。**

## 三、它到底怎么干活（讲给评委听的那条链路）

拿"腾讯跨式"这个例子走一遍，PPT 里这一条链就是主演示：

1. **听懂人话**：把"腾讯发财报、方向看不准、10 万港币、最多亏 5%"解析成机器能认的结构（标的 HK.00700、观点不确定、期限财报日、现金 10 万、风险预算 5%）。听不懂的字段不瞎猜，明确标出来。
2. **拿数据**：优先用富途的实时数据；没有就回放一份 2026-08-08 冻结的行情快照（演示永远有兜底，不会现场掉链子）。
3. **自己算**：价格怎么来的不靠大模型。Black-Scholes、美式二叉树、Greeks、加上价差手续费滑点之后的"真实成本"，全部是自研引擎一行行算出来的。算完给每条数字挂上来源和时间戳。
4. **过三扇门**：
   - 第一扇，值不值（Edge 门）：市场预期财报日波动 3.92%，但跨式的成本需要股价动 4.41% 才回本——3.92 < 4.41，门没过；
   - 第二扇，危不危险（Risk 门）：最大亏损 4,414 港币 ≤ 5,000 预算，现金够，流动性别太差——过，但带 3 条警告；
   - 第三扇，能不能下单（Action 门）：Edge 门没过，所以结论是 NO_TRADE，下单入口根本不给。
5. **盖审计章**：从听懂人话到最终结论，每一步都写进一条 JSONL 日志，每条记录用 SHA-256 哈希链串起来。改掉任何一行，后面的章全部对不上。评委问"数字可信吗"，答案是：**可追溯、不可篡改**。
6. **十个人吵一架**（这是 Agent 的部分）：结论出来之后，再让十个 AI 角色开一轮辩论——数据官、新闻分析师、期权策略师、风控、审计……每个人只许说人话和引用证据，不许算数。最后主席总结共识。真实跑过一次：67 秒，十个角色，共识是"反对买"（oppose/high），和引擎的 NO_TRADE 一致。

一句话给评委：**大模型只负责说话，不负责算数；算数的都是能复现、能审计的代码。**

## 四、为什么这个项目是个"Agent"而不是个计算器

评委那关有一道题："这不就是个期权计算器吗？"

不是。计算器需要你把所有数都喂给它；Agent 做的是从一句话出发，自己决定问什么、查什么、算什么、怎么说，失败了自己降级（数据源挂了就回放快照，没 API key 就跳过辩论），最后把"为什么"讲清楚。人只在最后一道关出现：下单之前，必须本人点确认。

顺带说一句我们的技术底牌：整套编排层跑在 **DeepSeek Harness**（DSH，可以理解成"DeepSeek 出的 Agent 开发台子"）上，我们项目本身就是一个可以拆下来给别人复用的**大号插件**。评委如果问"你们用什么框架"，这句既回答了问题，又顺手把"开放复用"那 5% 的分数拿了。

## 五、评委手里的分数，我们打算怎么拿

评委按六项打分（总分 100）。翻译成人话，每项我们手里有什么：

| 评委看什么 | 占多少 | 我们拿什么去接 |
|---|---|---|
| 这场景是不是真问题 | 25% | 腾讯财报跨式是真实高频场景；竞品分析做过（moomoo、moontower 都比过） |
| Agent 能力与任务闭环 | 25% | 上面六步链路 + 十角色辩论，从一句话到决策卡全程闭环，每步有审计 |
| 产品体验与 Demo | 20% | 四面板终端（对话/期权链/策略账户/事件审计）+ 截图 + 可录屏 |
| 技术实现深度 | 15% | 自研定价引擎、typed Gateway、367 个测试全绿、DSH 编排层 |
| 安全合规可追溯 | 10% | 这是我们的主场：模拟盘、人机确认、审计哈希链、非投资建议声明 |
| 开放复用 | 5% | 9 个 skill、架构文档、插件模板，代码已公开（GitHub: Alyosha28/GOAi_competition） |

## 六、PPT 建议的讲故事顺序（16 页以内）

1. 封面：产品名 + 一句话"敢说'别买'的期权决策终端"
2. 开场就讲那个诚实结论：同一份数据，我们给出 NO_TRADE，讲为什么（先立住"诚实"这个人设）
3. 痛点：信息散、数字虚、规则乱、LLM 编数
4. 用户：一句话（用富途的、懂期权的个人投资者）
5. 产品是什么：四面板终端 + 对话入口，截图说话
6. 走一遍主流程：一句话 → 决策卡（六步链路图）
7. 决策卡特写：花多少、亏多少、什么情况下赚、数据是哪一刻的
8. 三扇门：Edge 没过（3.92% < 4.41%）、Risk 带警告过、Action 拦截
9. 数据层：富途 + 冻结快照回放（演示永远不崩的原因）
10. 技术：自研引擎算数 + LLM 只说话 + 审计哈希链
11. 十角色辩论：67 秒、共识 oppose/high、离线自动回退
12. 编排层：DeepSeek Harness 上的"大号金融插件"，可逆效应/不可变版本/人机审批
13. 合规边界：非投资建议、模拟盘、人机确认、不替代专业决策
14. 竞品与差异：为什么 moomoo/moontower 没做这件事
15. 团队 + 路线：初赛做什么、复赛接 Live 行情与模拟确认闭环
16. 收尾：回到那句"NO_TRADE 是成功结果"——一个敢劝你别买的工具，才是能陪你长期做决策的工具

## 七、可以放心用的数字（全部有出处，别改）

- 盈亏平衡：股价要动 4.41% 才回本；市场预期只动 3.92% → Edge 门 FAIL
- 成本 4,414 港币（2 张 480 跨式，ask 口径）；最大亏损 ≤ 5,000 预算 → Risk PASS
- 历史回测：业绩跨式 d+2 平均 -7.8%、胜率 36%（负期望，佐证"不买"不是拍脑袋）
- IV 37.4%、IV Rank 72.9；IV crush 最差情景 -711 港币
- 367 个测试全绿；审计链 83 条记录哈希连续；辩论 67 秒、38,838 tokens、共识 oppose/high
- 数据快照：2026-08-08 11:56（周末收盘冻结），sha256 可验

所有数字的原始出处：`presentation/facts.md`（别去翻 JSON，那个文件就是为 PPT 准备的权威事实表）。

## 八、哪些话绝对不能说

- 不能说"帮你赚钱""收益可达"——我们是研究工具，不是投资建议；
- 不能说"自动下单"——比赛版本只有模拟盘，且任何模拟订单必须用户本人确认；
- 不能说"替代券商/理财顾问的判断"——规则明确禁止；
- 不要用 8 月 8 日那两笔旧模拟单做证据——它们是早期原型，已标记 legacy，不作为发布证据。

## 九、留一个活口，别把故事讲死

我们还有一个没做完的事：实时行情还没接进界面，现在的演示跑的是冻结快照。PPT 里**大方承认**这一点，然后说这是复赛的计划——这不丢人，它正好证明：产品今天的每一句结论，都只基于它真的拿到的数据。一个在快照上就敢说 NO_TRADE 的系统，接上实时数据之后的行为，评委信。
