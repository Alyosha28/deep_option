# GOAI 主 Demo 演示脚本（2026-08-15 版，含评审修复新能力）

> 环境：`python -m src.ui_server --port 8000`（独立模式，评审机不依赖 DSH）。
> 数据：腾讯 HK.00700 冻结快照（REPLAY，2026-08-08 捕获）。
> 全程台词要点：所有数字来自冻结快照与自研引擎，LLM 不产生数字；能力宣传不超过已验证切片。

## 0–15 秒：能力声明首屏（评审修复②）

总览顶部能力条，逐项指读：

- **当前切片：P0a · Replay 只读** ——「先讲清我们是什么：研究工具，不是下单工具」
- **数据模式：回放 / 冻结 快照 · 快照时间 2026-08-08 11:56 · 非实时行情** ——「数据是周末收盘冻结快照，界面不冒充实时盘」
- **支持范围：HK.00700 · 腾讯控股（P0 范围以冻结快照为准）** ——「港美股是产品方向，当前已验证切片是腾讯」
- **最近分析耗时** ——「产品自带度量，每次分析耗时可查」

点「运行管线（Replay）」按钮（或 F5）展示一键重跑。

## 15–35 秒：对话输入（研究助理）

命令条输入：`腾讯业绩快到了，方向不确定。账户 10 万港币，单笔最多亏 5%，帮我看看跨式` → 发送。

- 展示研究助理抽屉：五阶段进度条（理解请求 → 读取数据 → 重算损益 → 检查风险 → 更新工作台）
- 说明：场景由确定性解析器结构化（观点/现金/风险预算/期限），LLM 只编排与解释

## 35–75 秒：确定性管线与十角色辩论

- 五阶段管线重算（约 10–15s）→ 十角色辩论（有 DeepSeek key 时约 60s，无 key 自动离线回退，Demo 不崩）
- 强调：**LLM 只出文字结论与证据引用；verdict、数字、门控全部来自引擎**；编造的 evidence id 会被白名单过滤记入 dropped_refs（可在审计视图看到）

## 75–105 秒：决策卡与「下一步」（评审修复①）

切到「决策卡」视图：

- 结论：**先不交易（NO_TRADE）** ——「这是成功结果：Edge 门 3 项未通过——预期波动 3.92% < 盈亏平衡所需 4.41%」
- 关键证据三条（含来源与捕获时间）
- 什么会改变结论：实际波动超盈亏平衡 / 换 8/28 到期或价差结构 / Live 行情后成本变化
- **下一步动作区**：点「导出决策卡」→ 下载 JSON + SHA-256 提示（可溯源导出）；点「修改条件重算」→ 研究条件面板展开，改风险预算 2% 重算，展示结论变化
- 边界声明指读：「P0a Replay 只读 · 模拟提交未启用（P0c 未毕业）」

## 105–120 秒：审计链与度量（评审修复③④）

切到「审计」视图：

- **哈希链状态：链完整 · 共 95 条**（引擎侧校验 prev_hash 衔接）
- 事件明细：角色输出（stance/confidence/结论）、辩论共识、被拒引用（dropped_refs 红字徽章）——「这是可核验的溯源：每个结论都能回到审计链」
- 会话度量面板：事件/verdict 分布 + 平均耗时——「产品指标可度量：首次价值时间、耗时分布」

## DSH 加演（可选）：goai-options agent preset（2026-08-15 已验证）

> 前提：已跑 `harness\fix_dsh_tool_visibility.ps1`（新建会话即生效，无需重启，
> 已实测）；goai 插件族已按 `harness\bootstrap.ps1` 指引在 cordis 预设会话
> 注册（goai-core/run/chat running）。

台词与动作：

1. 设置 → Agent 预设 → **GOAI Options Terminal** → 新建会话（工作目录 F:\GOAi_competition）。
2. 第一句话：「腾讯 0700 业绩前方向不明，账户 10 万港币，评估跨式」。
3. 演示 Agent 的开场披露：先说明 goai_* 工具可用/不可用与兜底路径，不假装实时。
4. 说「用 goai_state 看当前决策卡」→ Agent 直接调用 `goai_state`，照抄引擎数字：
   NO_TRADE / LOW_EDGE(3 FAIL) / PASS(3 WARN) / 快照 FROZEN / snapshot 短哈希；
   并明确“完整 sha256 需读决策卡原文”，不编造数字。
5. 说「调用 goai_chat：腾讯 0700 业绩前方向不确定，账户 10 万港币，评估跨式」
   → 管线 + 十角色辩论，共识 `oppose/high`，结论仍 NO_TRADE（已实测）。
6. 补一个边界测试：「帮我实盘下单」→ 硬阻断 + 模拟盘/人机确认说明。
7. 收尾：「这就是 DSH 原生的大号金融插件：preset 管 Agent 能力，插件族管引擎工具，
   Python 引擎管数字，审计链管溯源。」

注意：动态插件是进程级资产——DSH 每次重启后都要重新注册插件族；未注册时
Agent 按 persona 自动回退独立模式 CLI（已实测）。
