# GOAI Deck — Design Lock v4（数据新闻风 / Data-Journalism）

> 唯一设计来源。重构 = 仅视觉层重做：16 页叙事顺序、结论、**全部数字与来源**与 v3 一致，零数值改动。
> 文案松绑：导语/注脚可微调措辞但不可改义；金句只在指定页保留；取消每页强制小结条。
> 生成每页前重读本文件。页面中禁止出现锁文件之外的颜色与字体。

## 1. Canvas & Grid

- Canvas: 960 × 540（16:9），页边距 **48**（内容区 x: 48–912，宽 864）
- 报头区 y=0–126；内容区 y=142–496；页脚区 y=506–532
- 栏网：整宽（864）/ 双栏（420+420，缝 24）/ 三栏（272×3，缝 24）/ 左右不对称（主 552 + 侧 288，缝 24）
- 节奏原则：**每页版式由内容形态决定**（统计带 / 规则表 / 分栏 / 管道 / 时间线），禁止 15 页共用同一骨架
- 分隔只用发丝规则线与留白；面板仅两种：白面板（$panel + 1px $hairline 边）与墨面板（$ink 底 + $paper 字）

## 3. Typography

- 标题/金句/大数字：中文 SimSun Bold + 拉丁 Georgia Bold（衬线）
- 正文/表格/注脚：中文 Microsoft YaHei + 拉丁 Arial
- 等宽（哈希、代码、审计链、代号）：Consolas + Microsoft YaHei
- 层级：页标题 28 / 导语 12 / 正文 11.5 / 小字 10.5 / 注脚 9.5 / 来源线 9 / 大数字 30–48 / kicker 10（Arial Bold，字距 2.5，大写）
- 正文字号下限 9.5（仅来源线可用 9）；v3 的全页 9.5 正文不再允许

## 4. Components（页级骨架）

### 4.1 报头（每个内容页固定）
- kicker：`(48, 28)` `$kicker`，格式 `SECTION · NN`（大写）
- 页码：右对齐 `(812, 28, 100, 14)`，Georgia 10 `$faint`，格式 `NN / 16`
- 标题：`(48, 48, 864, 38)` `$display` 28px，结论式单行（超长降 26）
- 导语：`(48, 90, 864, 18)` `$standfirst` 单行
- 双规则线（数据新闻签名）：3px `$ink` 粗线 `(48, 118, 864, 3)` + 0.75px `$ink` 细线 `(48, 124.5, 864, 0.75)`（用 shape rect 实现）
- 封面/结尾页不用此骨架（各自有专用版式）

### 4.2 页脚（每页固定）
- 发丝线 `(48, 506, 864, 1)`（line 元素，$hairline）
- 左：来源行 `(48, 512, 700, 14)` `$source`，格式 `数据/来源：xxx`（沿用 v3 各页来源文字）
- 右：`GOAI 港美股期权智能终端` `(612, 512, 300, 14)` `$source` 右对齐

### 4.3 规则表（ruled table）
- 无竖线、无斑马纹；表头上缘 1.5px $ink 线 + 表头下缘 1px $ink 线；数据行间 1px $hairline
- 表头 Arial Bold 10.5 `$ink`；数据行 10.5 `$ink`；数字列右对齐 Georgia
- 强调行：$primaryA 底或 $ink 底 + $paper 字（竞品页 GOAI 行用后者）
- 涨跌数字着 $up/$down，亏损加负号不加括号

### 4.4 统计格（stat cell）
- Georgia Bold 数字（30–44，$ink；裁决/关键值可用 $primary）+ 下方法标签（$cap 或 Arial 10 `$sub`）
- 多格并列时用竖向发丝线分隔，不用卡片框
- 数值一律带引号字符串；大数字加千分位

### 4.5 墨面板（verdict panel）
- `$ink` 底 + 内边距 20；面板内小标签 Arial Bold 9.5 字距 2 `#9AA3AF` 大写
- 面板内大结论 Georgia Bold 30–40（$paper 或 $primary 的亮色变体 #7FA6FF 不用——结论字用 $paper，仅关键标记可用 #86EFAC/#FCA5A5 亮绿/亮红）
- 仅用于：02 裁决、06 Hero 结论、16 收尾通栏；其他页禁用墨面板

### 4.6 金句（仅 03、06、16 保留）
- Georgia 46px `$primary` 左引号 + 衬线 15px bold `$ink` 引语，无左轨、无「金句」字样
- 03：右栏结果区；06：底部通栏；16：墨面板内收束

### 4.7 状态徽章（status chip）
- 圆点（8×8 ellipse，语义色）+ Arial Bold 10 大写英文代号 + 下方 $cap 中文释义
- NO_TRADE=$primary / BLOCK=$down / DRAFT_ONLY=$warn / READY_FOR_CONFIRMATION=$up

### 4.8 流程管道（pipeline）
- 编号 Georgia Bold 18 `$primary` + 阶段名 Arial Bold 12 `$ink` + $cap 说明
- 阶段间用 `→`（Arial 14 `$faint`）或 1px 线 + stealth 箭头，禁止厚重箭头块

### 4.9 终端窗（仅 05）
- 白面板 + 1px $hairline 边 + 顶部 26px `$ink` 标题条（左：红黄绿 7px 圆点；标题 Consolas 9.5 `$paper`）
- 象限内小标题 Arial Bold 9.5 `$primary`；数据行 Consolas 9.5 `$ink`；警示行 `$warn`/`$down`
- 右栏图例：编号 + Arial Bold 11 名 + $cap 说明

### 4.10 时间线（仅 16）
- 水平主轴 1px $ink + 节点圆点（语义色 8px）+ 日期 Georgia Bold 12 + 阶段名 Arial Bold 11
- 阶段块内列 $cap 要点（最多 4 条）；状态词用 已完成=$up / 开发中=$warn / 待验证=$faint

### 4.11 架构分层（仅 10）
- 5 层水平条（高 44，缝 10）：白面板 + 1px $hairline；层名 Arial Bold 11.5 `$ink` + 右侧 Consolas 9.5 `$sub` 注释
- 层间向下 stealth 小箭头（1px `$faint`）；审计链层用墨面板反白收尾
- 右侧栏 3 个注记块（$primaryA 底或发丝线上）：$cap 标题 bold + 10.5 正文

## 6. 内容规则

- 数字、代号、来源、结论文字 = v3 原样搬运，逐个核对；一律带引号字符串
- 可删：每页强制金句、强制小结条、重复性装饰语；可微调：导语/注脚措辞（不改义）
- 每页底部一行结论（10.5 `$sub`），直接陈述，不写「小结」字样（01/16 除外）
- 每页 notes 保留并更新为新版式说明
- 动画：保留 v3 的克制动效风格——仅 fade-in / wipe-in / rise-in / zoom-in，每页 ≤12 条动画、按视觉分组，触发以 withPrevious/afterPrevious 为主；页级不做动画
