## 02 · 结论先行：我们最骄傲的运行，结论是「不买」

- **标题**：同一份数据，别的产品想卖给你，我们劝你别买
- **副题**：2026-08-08 冻结快照 → 决策卡：NO_TRADE
- 子点：
  - 腾讯财报前（8/14 到期、480 跨式、2 张，成本 4,414 港币）：市场预期波动 **3.92%**，回本需要 **4.41%**——差 0.49 个百分点，Edge 门 FAIL；
  - 历史佐证：11 期财报跨式 d+2 平均 **-7.8%**、胜率 **36.4%**——不是一次巧合，是负期望；
  - IV crush 压力测试：即使方向对了，波动率回落 20% 时最差仍亏 **-711 港币**；
  - 结论：**NO_TRADE**。不给下单入口，只给解释和调整建议。
- 金句：在金融产品里，敢于「不买」比敢于「买」难得多——我们把难的那件事做成了产品。
- 注脚：`data/decision_card_2026-08-13.json`；快照 2026-08-08T11:56:30+08:00，sha256 `cf567c5985ea…`

## 03 · 痛点：散户做期权研究的四个坑

- **标题**：会看 Call/Put 的散户，卡在四件事上
- 子点：
  1. **信息散**：行情、合约规则、定价、风险、账户，分散在五个页面；
  2. **数字虚**：界面上的价格 ≠ 真能成交的价格（价差、手续费、滑点没人算）；
  3. **规则乱**：港股期权美式行权、实物交割、持仓限额，照搬美股经验会踩坑；
  4. **大模型编数**：ChatGPT 能"算"出一个看起来很专业的假数字——在金融里，这是致命的。
- 金句：通用大模型的问题不是不会说话，是它不知道自己不知道。
- 注脚：PRD §1.2

## 06 · 主流程：从一句话到决策卡，六步闭环

- **标题**：一句话进去，一张可核验的决策卡出来
- 子点（六步链路图）：
  1. **听懂人话**：解析标的/观点/期限/现金/风险预算，缺的字段显式标注，不瞎猜；
  2. **取数**：Futu OpenAPI 优先；冻结快照回放兜底——演示永远不崩；
  3. **自己算**：BS、美式二叉树、Greeks、可成交成本，全部自研引擎，每个数字带来源和时间戳；
  4. **过三扇门**：Edge（值不值）/ Risk（危不危险）/ Action（能不能下单）；
  5. **盖审计章**：JSONL + SHA-256 哈希链——改掉任何一行，后面的章全部对不上；
  6. **十个人吵一架**：十角色辩论补充文字研判，LLM 只说话、不算数。
- 注脚：docs/DSH_ARCHITECTURE.md；README

## 08 · 三扇门：Edge 没过，Risk 带警告过，Action 拦截

- **标题**：三门控各司其职，结论不由任何人"感觉"决定
- 子点：
  - **Edge 门（值不值）**：3 项检查全部 FAIL → LOW_EDGE（预期波动 < 回本；回测负期望；crush 情景亏损）；
  - **Risk 门（危不危险）**：PASS + 3 条 WARN（持仓限额/LOP 未验证、费用滑点 policy 未冻结、美式提前行权风险）；
  - **Action 门（能不能下单）**：NO_TRADE，阻断原因 = Edge 未过——**下单入口根本不出现**。
- 金句：PASS 不代表赚钱，只代表"按当前数据，风险在预算内"。
- 注脚：facts.md §1（edge_gate / risk_gate / action_gate 原文）

## 09 · 数据层：双通道，演示永远不崩

- **标题**：富途实时 + 冻结快照回放，两条腿走路
- 子点：
  - Futu OpenAPI：56 个 API、5 个市场、默认模拟盘；美股期权数据同样用富途（已拍板）；
  - ReplayGateway：与 Live 同合同的确定性回放，快照带 SHA-256 身份与 60 秒一致性窗口；
  - 边界纪律：Agent 只有唯一粗粒度只读入口（refresh_decision_inputs），拿不到 SDK/Bash；
  - 授权红线：富途数据禁止打包再分发，原始授权快照不入公开仓库。
- 注脚：PROJECT_STATE §5；PRD §7

## 10 · 技术：算数的从来不靠大模型

- **标题**：数字铁律——LLM 只说话，引擎只算数，哈希链只作证
- 子点：
  - 自研引擎：欧式 BS + 美式二叉树 + IV 二分求解 + bump-and-reprice Greeks；理论价值与可成交成本分栏；
  - LLM 输出强约束：只解析为文本 + 枚举（stance/confidence）+ 证据引用，解析器强制执行；
  - 证据白名单：LLM 编造的 evidence id 会被记入 dropped_refs 丢弃；
  - 工程可信度：**367 个测试全绿** + 157 subtests（208.5 秒），审计链 83 条记录哈希连续。
- 金句：大模型负责说话，代码负责算数，哈希链负责作证。
- 注脚：PROJECT_STATE §11；facts.md §0.5
