05 · WHY AGENT                                                                GOAI · TERMINAL — 初赛评审  05/16

可信来自分工： LLM 管理解与编排，数字全由工具产出
三种解法对比：固定计算器只会算、通用 LLM 会编数字、 GOAI Agent 让数字全部出自工具。

维度              固定计算器                                           通用 LLM        GOAI Agent

场景理解            读不懂「业绩前方向不确定」                                   听得懂场景，还能追问补全  解析场景、编排工具、写结论

数字从哪来           公式写死在代码里                                        概率生成，会编数字     确定性工具产出

可复算 / 可核验       能复算，但只会预设项                                      同问不同答，无法核验    SHA-256 审计，数字可溯源

出错的表现           报错 → 改代码重跑                                      错了不自知，还很笃定    证据不足就 NO_TRADE

判决              会算，但只会算                                         会编，但数字不可信     理解归 LLM ，数字归工具

&gt;数字的每一次出现，都要答得上「谁算的、依据什么、何时」。

结论     分工让「会编」退场：理解与表达归 LLM ，数字与溯源归工具；数字编造目标为 0 。
