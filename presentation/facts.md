## 3. 决策管线阶段名称与顺序

来源：`src/decision_pipeline.py`（模块 docstring 与 `run_pipeline`）、README.md、docs/PRD.md §3.3

**五阶段（代码原文）**：场景解析 → 数据获取 → 自研引擎 → Edge/Risk/Action 门控 → 决策卡 + 审计留痕。

对应到页面叙事（任务口径 → 代码阶段）：
1. 场景解析（`parse_scenario`；未知字段不补造，敏感字段直接拒绝）
2. 冻结快照（`load_frozen_snapshot`，FROZEN 数据加载）

| 枚举 | 含义 |

## 5. 数据层组件

来源：README.md「Futu Gateway 边界」、PROJECT_STATE.md §5 / §5.5、docs/PRD.md §3.1

- **DataEnvelope**：统一 LIVE/REPLAY、来源时间、freshness、typed error 与 SHA-256 快照身份。
- **FutuLiveGateway**（`src/futu_adapter.py`）：长期只读 Context、loopback 健康检查、行情/期权/组合报价和脱敏账户风险摘要；惰性导入 SDK；无下单/改单/撤单/解锁方法。
- **ReplayGateway**（`src/replay_adapter.py`）：与 Live 同合同的确定性离线回放，不导入 Futu SDK；默认只读带完整 schema、内容哈希和业务语义校验的 canonical JSONL；`as_of_utc` 构造时固定 + 默认 60 秒一致性窗口，不按调用顺序拼接批次；旧 OpenD 日志包裹的 `.json` 仅在 `allow_legacy=True` 时以 `PARTIAL/unverified` 迁移，不能作为正式发布证据。
- **SnapshotRecorder**（`src/snapshot_recorder.py`）：线程安全 JSONL 录制（`data/snapshots/`）；原始授权行情只保存在本地，不重新分发。
- **DecisionInputService**（`src/decision_inputs.py`）：Agent 侧唯一粗粒度只读入口 `refresh_decision_inputs`；不暴露 SDK Context、Bash 或任意方法调用权。
- **只读边界**：Gateway 无下单、改单、撤单或解锁方法；写操作隔离在只读边界之外；P0a 不导入 Futu SDK、不连接 OpenD；P0b 才装配 FutuLiveGateway（仅读取能力 + 服务端账户别名）；P0c 模拟执行是独立边界。
- **OpenD loopback**：`127.0.0.1:11111`；行情 Context 用 SDK 官方异步初始化与连接等待上限；健康检查未通过只返回 typed error，不会静默切换为 Replay；Gateway 不会自动启动、登录或解锁 OpenD。
- **20s 可终止 worker**（`src/futu_account_worker.py`）：真实账户读取放在固定 schema、20 秒硬截止且可终止的本地子进程 worker 内，超时返回 typed `ACCOUNT_UNAVAILABLE`，避免 SDK 同步构造无限重试阻塞 Agent 进程；该 worker 是内部安全边界，不是 MCP，不暴露任意调用。
- **Replay 兜底**：Live 失败可安全回放；连接失败时可以建议 Replay，但必须由用户接受数据模式变化；降级路径明确（Live 不可用 → 明确进入 Replay / DRAFT_ONLY，不静默切换）。
- **yfinance 429 教训**（PROJECT_STATE.md §9）：yfinance 免费源限流不稳定（2026-08-08 实测 429），演示必须快照回放；Alpaca/Yahoo 仅为代码占位（`src/fallback_adapter.py`），不作为正式数据方案。
- 不建 Futu MCP：单一 Python 宿主直接扩展 typed Boundary，避免增加协议层与工具发现攻击面。

## 6. 自研确定性引擎

来源：README.md「自研引擎边界」、docs/PRD.md §5、PROJECT_STATE.md §5.5

- 实现（`src/pricing_engine.py`）：**欧式 Black–Scholes**、**通用美式二叉树**、**IV 二分求解**、**bump-and-reprice Greeks**；Greeks 已对齐 OpenD 期权报价口径。
- 项目不声称发明 BS 或二叉树；自研工作是：港股产品规格解析与模型路由；IV、Greeks 和情景损益的可复算实现；bid/ask、费用、滑点和 tick 的 executable-cost 口径；Edge、账户风险和动作门控；数据、计算与决策审计。
- **港股规格**（PRD §5.2）：港股个股期权 = 通常**美式** + **实物交割**，支持提前行权与离散股息的数值模型，特别风险为除息、assignment、公司行动、合约调整；港股指数期权 = 通常**欧式** + **现金交割**，风险为结算价与到期规则。每次计算必须先解析当前合约规格，不凭代码前缀或提示词猜测；乘数、报价单位、tick、到期、费用和资本调整状态缺一不可。
- 其他港股规则事实（PROJECT_STATE.md §4 知识摘要）：持仓限额单类单方向 5 万张、LOP 申报 1 千张；IV crush 常见 20–50%。
- **executable-cost 分栏**（PRD §5.2）：理论价值（模型比较）/ mid（观察，不能冒充成交成本）/ 买入成本（两腿 ask × 乘数 + 费用 + 滑点）/ 平仓价值（按可执行 bid/ask 方向估算）/ 模拟限价（遵守 tick，确认前刷新）。
- Hero 引擎输出：iv_solved 主到期 call 0.4373 / put 0.4216（次到期 0.356 / 0.3503）；Greeks 见 §1。
- 当前状态边界（PRD §5.1）：离散股息、费用/滑点和调整合约处理尚未完成；完成前不得把原型结果称为港股生产级定价。当前引擎仍是原型，不能用于真实资金决策。

## 7. 风险硬门与审计链

来源：docs/PRD.md §5.3 / §7、README.md 核心原则、PROJECT_STATE.md §5

- **Edge 与 Risk 分离**：Edge 判断（隐含波动 vs 事件波动、成本、IV crush）与账户/风险硬门是独立阶段；允许明确 `NO_TRADE`（差异化点，PRD §1.4）。
- **Risk 一票否决**（PRD §5.3，以下任一失败不得出现模拟确认入口）：关键行情陈旧/缺失或数据模式非 Live；合约规格、乘数、行权/交割或公司行动无法验证；最大亏损超风险预算或现金不足；数量、流动性、报价质量或持仓/申报规则不满足；关键事件证据冲突或无法证明当时可得；审计记录失败。
- **审计链**：JSONL（`research/audit/audit_log.jsonl`）+ SHA-256 哈希链（`futu-options-agent/scripts/audit_log.py` 写入）；每条记录链上前一条；Hero 共 7 条记录（事件名与哈希见 §1）。
- **防注入**：`decision_pipeline.py` 场景解析直接拒绝敏感字段（password/secret/token/api_key/account_id/order_id 等），遍历上限 10,000 项；外部文本按不可信数据处理，不能修改数值、风控或权限；LLM 不接触 SDK、账户密钥与订单工具；不注册实盘工具。
- **动作边界**：比赛版本仅支持 Futu 模拟盘，且模拟动作必须由用户独立确认；用户确认只授权当前模拟订单摘要，参数变化必须重新确认；重复点击不得产生重复订单；任一腿结果未知或组合部分提交时不自动重试/补腿/撤腿/对冲，页面置顶显示券商事实、潜在暴露和人工下一步；跨会话默认不记忆账户、风险预算、观点、订单或确认。
- **PASS 的固定含义**（PRD §7）："当前数据、规则和风险门通过"，**不表示盈利、成交或投资建议**。

## 12. 脱敏确认（本文件已主动排除的敏感类别）
